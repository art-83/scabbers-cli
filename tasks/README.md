# Tasks

Local backlog for planned Scabbers work. New tasks start in **To do**. This directory records plans; creating a task does not execute it or grant permission for external actions.

| Status      | Meaning                                              |
| ----------- | ---------------------------------------------------- |
| To do       | Recorded, implementation not started                 |
| In progress | Implementation underway                              |
| Done        | Acceptance criteria verified, with evidence recorded |

Create one Markdown file per task and link it below. Keep its status and this index consistent. Record validation evidence before marking a task Done.
